# 행동 호환성 및 소스 경계

<p align="center">
  <a href="BehaviorCompatibility.md">English</a> | <strong>한국어</strong>
</p>

SlugcatInMyMonitor는 Rain World의 게임 바이너리나 자산을 배포하지 않으면서,
Windows 데스크톱 환경에서 Slugcat의 **관찰 가능한 동작**을 재현하는 것을 목표로 합니다.

이 문서는 호환성 작업을 수행할 때 공개 저장소에 무엇을 남길 수 있는지에 대한 기준을 정의합니다.

## 공개 호환성 문서에 포함할 수 있는 내용

- 사용자에게 보이는 동작과 기대 결과
- 이동, 렌더링, AI, 능력에 대한 상위 수준 요구사항
- 이 프로젝트 안에서 재현할 수 있는 회귀 시나리오
- 데스크톱 구현 자체에 관한 아키텍처 결정
- 사용자의 Rain World 설치본에서 자산을 복사하지 않고 읽는 규칙
- 제3자 메서드 본문을 옮기는 대신 프로젝트 테스트 기대값으로 표현한 측정값이나 튜닝 기준

## 공개 호환성 문서에 포함하지 않는 내용

- 디컴파일된 소스 코드 또는 복원한 제3자 메서드 본문
- IL/ILDASM 출력, 메서드 토큰, RVA, 로컬 바이너리 오프셋 또는 디컴파일러 덤프
- 독점 DLL, 실행 파일, 추출한 텍스처·오디오 데이터 또는 기타 게임 파일
- 개인 역분석 세션을 재현하는 데만 필요한 상세 로컬 경로, 해시 또는 추출 로그
- 제3자 구현의 표현을 그대로 유지하는 복사된 주석이나 소스 형태의 의사코드

## 구현 작업 흐름

1. 데스크톱 펫에서 재현해야 하는 동작을 먼저 설명합니다.
2. 조사 결과를 작은 행동 수준 명세나 회귀 테스트로 바꿉니다.
3. 그 명세를 이 프로젝트의 자체 아키텍처와 타입을 사용해 구현합니다.
4. PR에서는 디컴파일러 출력에 의존하지 않고 결과 코드를 검토할 수 있어야 합니다.
5. 게임 바이너리, 추출 산출물, 상세 개인 조사 노트는 git 밖에 보관합니다.

데스크톱 애플리케이션은 런타임에 사용자의 로컬 Rain World 설치본에서 호환 가능한
자산을 읽을 수 있습니다. 해당 자산은 외부 입력이며 이 저장소나 MIT 라이선스의 일부가 아닙니다.

## 현재 아키텍처 호환성 목표

공개 구현은 고정 스텝 시뮬레이션, 연결된 신체 파츠, 데스크톱 AI가 생성하는 가상 입력,
절차형 자세 생성, 데스크톱 창 충돌, 로컬에서 발견한 atlas 데이터 기반 렌더링을 중심으로
구성됩니다. 이는 이 프로젝트의 행동/아키텍처 목표이며, 이 문서에서는 Rain World의
소스 수준 구현 설명을 의도적으로 다루지 않습니다.

이 정책은 저장소 위생을 위한 가이드이며, 특정 코드가 저작권을 침해하는지 여부에 대한
법률 의견이나 선언이 아닙니다.
